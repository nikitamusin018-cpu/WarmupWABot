WHATSAPP PANEL — QR ONLY

Изменения:
1. Вход по номеру/коду убран из Telegram-бота.
2. Добавление аккаунта теперь только через QR.
3. QR отправляется только владельцу в Telegram, на сайт QR не выводится.
4. Data URL QR преобразуется в PNG Buffer перед отправкой в Telegram — это исправляет основную проблему, когда QR создавался, но Telegram его не получал.
5. За одну попытку подключения отправляется только первый QR, чтобы обновление QR не спамило чат.
6. Остальные файлы проекта сохранены.

Запуск:
npm install
npm start

В отдельном окне:
npm run bot

ВАЖНО:
В bot.js сейчас находится токен Telegram-бота из загруженного проекта. После публикации/перед использованием на реальном сервере обязательно перевыпустите токен через BotFather и замените его.
